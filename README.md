# Academic Course Information Portal

##  Scholara Course Hub

**Scholara Course Hub** is a responsive academic course information portal developed using **HTML, CSS, JavaScript, and XML**.  
It simulates a real university website where users can explore different academic programmes including foundation, undergraduate, and postgraduate levels.

The system focuses on dynamic content loading, structured UI design, and client-side validation without relying on HTML5 built-in validation features.

---

##  Features

-  Display of academic courses (Foundation, Undergraduate, Postgraduate)
-  Dynamic course loading from external XML file
-  Interactive course cards UI
-  Filtering system based on academic level
-  Custom JavaScript form validation (no HTML5 validation used)
-  Fully responsive design for all devices
-  Clean and structured UI/UX layout
-  Improved accessibility and usability principles

---

##  Technologies Used

- HTML5 (Structure)
- CSS3 (Styling & Responsive Design)
- JavaScript (Logic & Validation)
- XML (External Data Source)

##  How It Works

1. Course data is stored in an external **XML file**
2. JavaScript fetches and parses the XML dynamically
3. Courses are displayed as interactive cards on the UI
4. Users can filter courses based on academic level
5. Enquiry form validates user input using custom JavaScript rules
